# Face Recognition System using OpenCV

A real-time face recognition system built with **Python** and **OpenCV** that uses the **LBPH (Local Binary Patterns Histograms) Face Recognizer** to identify individuals from a live webcam feed. The project is organized as a simple three-step pipeline: **collect → train → recognize**.

## Overview

This project demonstrates a complete face recognition workflow using classic computer-vision techniques:

1. **Face Detection** is performed with a **Haar Cascade Classifier** (`Classifiers/face.xml`).
2. **Face Recognition** is performed with OpenCV's **LBPH Face Recognizer**, which is fast, lightweight, and works well even on small datasets.
3. The pipeline captures face samples from your webcam, trains a model on those samples, and then identifies registered users in real time.

It is intended as an educational, easy-to-follow implementation that you can extend for attendance systems, access control, smart cameras, and similar applications.

## How It Works

```
 ┌──────────────────────┐     ┌────────────────────┐     ┌───────────────────────┐
 │ dataSetGenerator.py  │ ──► │     trainer.py     │ ──► │      detector.py      │
 │  Capture face images │     │ Train LBPH model   │     │ Recognize faces live  │
 │  → dataSet/          │     │ → trainer/...yml   │     │ from the webcam feed  │
 └──────────────────────┘     └────────────────────┘     └───────────────────────┘
```

1. **`dataSetGenerator.py`** — opens your webcam, detects your face in each frame, and saves up to ~100 cropped grayscale samples into the `dataSet/` folder, named like `face-<id>.<n>.jpg`.
2. **`trainer.py`** — reads every image from `dataSet/`, extracts the numeric ID from each filename, trains the LBPH recognizer, and stores the trained model at `trainer/trainer.yml`.
3. **`detector.py`** — loads the trained model, captures frames from the webcam, detects faces, predicts the matching ID, and overlays the person's name and confidence score on the video stream.

## Usage

Run the three scripts in order. Once you have generated and trained on a face, you do **not** need to repeat steps 1 and 2 unless you want to add a new person.

### Step 1: Generate the Dataset

```bash
python dataSetGenerator.py
```

- You will be prompted: `enter your id`. Enter a **numeric ID** (e.g. `1`, `2`, `3`).
- The script opens your webcam and starts saving cropped face images into `dataSet/`.
- It captures roughly **100 samples**, then automatically stops.
- Look directly at the camera and slightly vary your angle and expression for better results.

### Step 2: Train the Recognizer

```bash
python trainer.py
```

- Reads every image from `dataSet/`, parses the numeric ID from each filename, and trains the LBPH recognizer.
- Saves the trained model to `trainer/trainer.yml`.

### Step 3: Run the Recognizer

```bash
python detector.py
```

- Opens the webcam and draws a rectangle around any detected face.
- Predicts the ID using the trained model and displays the mapped name plus the confidence value.
- Lower confidence values indicate a better match.

## Adding New People

The mapping from numeric IDs to names is currently hard-coded inside `detector.py`:

```python
if   nbr_predicted == 1: nbr_predicted = 'Rafay'
elif nbr_predicted == 2: nbr_predicted = 'Wasay'
elif nbr_predicted == 3: nbr_predicted = 'Iqra'
elif nbr_predicted == 4: nbr_predicted = 'Kiran'
else:                    nbr_predicted = 'unknown'
```

To register a new person:

1. Run `dataSetGenerator.py` and assign them a **new unique numeric ID**.
2. Re-run `trainer.py` to retrain the model on the updated dataset.
3. Add a new `elif` branch in `detector.py` mapping their ID to their display name.

> Tip: For larger projects, replace the `if/elif` block with a dictionary or a small `names.json` file that you load at startup.

## Configuration Notes

- **Cascade classifier:** `Classifiers/face.xml` — standard Haar cascade for frontal faces.
- **Detection parameters** (in `dataSetGenerator.py` and `detector.py`):
  - `scaleFactor=1.2`
  - `minNeighbors=5`
  - `minSize=(100, 100)`
- **Sample crop padding:** `offset = 50` pixels around the detected face.
- **Sample count:** capture stops after `i > 100` images.
- **Model output:** `trainer/trainer.yml`.

You can tune these values to trade off speed, accuracy, and robustness for your environment and lighting conditions.

## Troubleshooting

| Problem | Likely Cause / Fix |
|---|---|
| `AttributeError: module 'cv2' has no attribute 'face'` | Install the contrib build: `pip install opencv-contrib-python`. |
| `dataSet/` folder error when saving images | Create the folder manually: `mkdir dataSet`. |
| Webcam window does not open | Another application may be using the camera, or index `0` is wrong — try `cv2.VideoCapture(1)`. |
| Recognition is inaccurate | Capture more samples under varied lighting/angles, then retrain. |
| `trainer/trainer.yml` not found | Run `trainer.py` before `detector.py`. |
| Detector window won't close | Click the window and press any key (the scripts use `cv2.waitKey`). You may need to add `cv2.destroyAllWindows()` and a quit key. |
